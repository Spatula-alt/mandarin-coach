# Mandarin Coach

Study Mandarin in 90-minute sessions: flashcards for 585 HSK 1-3 words with recorded audio, a tone trainer, shadowing and speaking practice.

Live at https://spatula-alt.github.io/mandarin-coach/

Built from `Dream Deck/mandarin-coach` with `python build.py`. Audio: Microsoft Xiaoxiao voice (edge-tts).
