# Language Coach

Learn Mandarin, Spanish (Latin American) or Japanese in 90-minute sessions: flashcards with recorded audio, a Mandarin tone trainer, Japanese kana and kanji quizzes, shadowing and speaking practice, and class invites with a coach view.

Live at https://spatula-alt.github.io/mandarin-coach/

Built from `Dream Deck/mandarin-coach` with `python build.py`. Audio: Microsoft neural voices (Xiaoxiao, Dalia, Nanami) via edge-tts.
